# Development

<p class="lead">Built with TypeScript, React and <a href="https://github.com/spicetify/spicetify-creator">Spicetify Creator</a>.</p>

First [install from source](install.html#from-source), then:

```powershell
npm run watch          # rebuild on save
spicetify watch -a     # second terminal: reload Spotify when the app changes
npm test               # unit tests (Vitest)
npm run site           # build this guide into site-dist/
```

How the demo clips are made: [docs/media/SHOTLIST.md](https://github.com/hellovvn/spicetify-prism/blob/main/docs/media/SHOTLIST.md).

The code lives at [github.com/hellovvn/spicetify-prism](https://github.com/hellovvn/spicetify-prism).
Bugs and ideas are welcome as [issues](https://github.com/hellovvn/spicetify-prism/issues).
